Install in a minute

Ad-hoc signed, so macOS asks for one extra confirmation on first launch.

Download

Get the .dmg or .app.zip from the Releases page.

Move to Applications

Drag SwiftPlayer into your Applications folder.

Launch it

Open it, then approve it once (see below). After that it opens normally.

First launch: macOS Gatekeeper
  • macOS 15 (Sequoia) or later: launch the app and dismiss the warning. Open System Settings → Privacy & Security, scroll down and click Open Anyway next to SwiftPlayer.
  • macOS 13–14: right-click the app in Finder, choose Open, then Open again.
  • Any version: run xattr -dr com.apple.quarantine /Applications/SwiftPlayer.app

Build from source

Requires Xcode 16+ and macOS 13.0+.

git clone https://github.com/scadavide55/SwiftPlayer.git
cd SwiftPlayer
open SwiftPlayer.xcodeproj
